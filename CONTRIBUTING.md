# Contributing to SnapPDF

Thank you for your interest in contributing!

Guidelines
- Fork the repository and create a branch named `feature/xxx` or `fix/yyy`.
- Keep changes focused and small; include tests where appropriate.
- Run linters locally: `pip install -r requirements.txt` then `flake8`.
- Open a PR against `main` with a clear description, testing steps, and screenshots if applicable.

Issue/PR templates
- File an issue with OS, Python version, SnapPDF version (commit), and a minimal reproduction.
- For UI changes include screenshots or a short GIF.

License
- By contributing, you agree your contributions will be licensed under the project's MIT License.

Optional
- Consider adding a CODE_OF_CONDUCT.md if you expect community contributors.
